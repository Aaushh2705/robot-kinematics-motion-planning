# robot-kinematics-motion-planning
Python implementation of forward kinematics, Jacobian-based inverse kinematics and trajectory generation for a serial robotic manipulator.
## Roadmap

- [x] Forward kinematics
- [x] Robot visualization
- [x] Analytical Jacobian computation
- [x] Numerical Jacobian validation
- [x] Numerical inverse kinematics
- [x] IK convergence analysis
- [x] Joint-space trajectory generation
- [x] Trajectory visualization
- [ ] Final validation and documentation
